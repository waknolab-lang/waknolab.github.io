WAKNO LAB — DEMO BOLD BRANDING

1. Dezarhivează ZIP.
2. Încarcă index.html și întregul folder assets în rădăcina repository-ului waknolab.github.io.
3. Commit changes; așteaptă 1-3 minute.
4. Deschide https://waknolab-lang.github.io/waknolab.github.io/

IMPORTANT: imaginile și videoclipul sunt ILUSTRATIVE, realizate din mockup-ul demonstrativ; nu reprezintă lucrări reale.

WHATSAPP / INSTAGRAM / TIKTOK: deschide index.html și caută const CONTACT={whatsapp:'',instagram:'',tiktok:''}; Completează numărul WhatsApp în format 407... și URL-urile complete pentru Instagram și TikTok. Până atunci butoanele afișează un mesaj informativ.

Video-ul este un montaj animat demonstrativ, nu filmare din atelier. Se poate înlocui ulterior cu un fișier MP4 real, păstrând numele assets/hero-demo.mp4.
